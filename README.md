# OpenPatient World

一个从生物过程到个人体验的患者世界模型交互实验室。当前版本：**0.2.0**。

**在线体验：https://interleukin2.github.io/openpatient-world/**

## 当前可用

- 可暂停、拖动旋转的五层粒子图谱；尊重减少动态效果设置，离屏与后台暂停渲染。
- 6 个原创合成角色、4 种情境、5 个显式可控变量。24 个组合不是 24 名真实患者。
- 可选 MBTI、3 种表达习惯，以及教育、经济、国家、语言、文化与族群背景标签。
- 12 轮连续会话：4 个快捷动作，或输入中文话语使用本地关键词规则匹配。
- 信任、焦虑、理解、表达与接受意愿随轮次更新；显示状态曲线和每轮规则依据。
- A/B 对照：同角色、同情境、同起点，仅改变 6 轮沟通动作序列。对照不修改当前会话。
- 导出已应用设定、情境、完整轨迹、事件、对照及规则版本；另可下载全部合成数据和接口字段。
- GitHub Issue 模板：角色构想和模型接入提案。

这是概念原型，不是临床系统、经过校准的个体数字孪生或人格测评。没有调用 LLM、基因组、细胞、生理或药代模型。没有跨就诊长期记忆、账户、数据库或自动自我改进。参考项目不是已集成服务，也不代表合作。

## 运行与部署

零运行时依赖、无需构建。

```sh
python3 -m http.server 4173 --directory docs --bind 127.0.0.1
```

浏览器访问 http://127.0.0.1:4173 。GitHub Pages 使用 `main` 分支的 `/docs` 目录。

```sh
node --test tests/engine.test.cjs
```

`docs/data.js` 管理合成角色、情境、规则与研究索引；`docs/engine.js` 是确定性的纯状态引擎；`docs/atlas.js` 只负责尺度示意，不产生生物数据。无需依赖或密钥。

## 规则与数据边界

所有分数是 0–100 的设计示意，不是概率、常模分数或临床指标。

初始状态：`trust = profile.trust`，`anxiety = profile.anxiety`，`understanding = profile.literacy`。

| 动作 | 信任基础变化 | 焦虑基础变化 | 理解变化 |
| --- | ---: | ---: | ---: |
| 倾听与共情 | +9 | -8 | +1 |
| 解释与确认 | +6 | -5 | +10 |
| 承认不确定性 | +5 | -3 | +5 |
| 施压与绝对保证 | -13 | +10 | -3 |
| 中性 / 未匹配 | 0 | 0 | 0 |

- 每种情境有显式的 `pressure`：复诊 1、隐私 1.1、现实条件 1.2、信息冲突 1.3。它是设计参数，不是患病风险。
- 施压的信任变化乘以 `pressure`；所有动作的焦虑变化乘以 `pressure`。
- 边界动作的信任额外增加 `0.04 * privacy`，演示回应隐私顾虑的假设。
- 表达意愿：`0.65 * trust + styleOffset - 0.12 * privacy - 0.1 * anxiety`。直接型偏移 22、详细型 16、慢热型 7。
- 接受意愿：`0.3 * trust + 0.25 * understanding + 0.45 * access - 0.1 * anxiety`。
- 每次更新后四舍五入并限制在 0–100。理解只在会话中变化，不会修改角色的初始健康素养。
- MBTI、教育、经济、国家、语言和族群标签不参与数值计算，也不决定临床状态。页面并不自动翻译回复。

文本匹配顺序：边界 → 施压 → 解释 → 共情；边界与施压同时命中时按中性处理。公开匹配词见 `engine.js` 的 `classify`。不理解语境、否定、讽刺或复杂句意；中性不表示低质量。需要严格控制条件时请选择快捷动作。回复来自模板，不是自由生成的对话。

A 序列为“共情、解释、边界”重复两次，B 为六次施压。每次从**已应用**的角色初始状态计算，而非当前会话末态；修改角色或切换情境会清空旧对照。未应用的表单编辑不会改变当前会话、对照或导出。重置仅重置已应用的会话。

这些权重仅用于演示反馈关系，尚无实证校准。接受意愿不等于实际依从性，页面也不预测疗效。

五层数据接口明确列出未接入字段。图谱中人体、双螺旋、细胞和关系网络均为程序化尺度示意，不是解剖重建、显微图像、实测组学或模型预测。

输入与对话仅存于当前页面内存。无分析追踪、第三方脚本、模型 API、Cookie 或 localStorage。刷新即清空。导出生成本地文件，不上传。托管服务仍可能记录普通 HTTP 访问日志。跳转 GitHub 后适用 GitHub 的数据处理方式；不要提交真实病历或基因数据。

## 研究方向

以可替换的专病模型连接生物状态和患者行为；用实际观测校准模型；验证信息披露与关系记忆；冻结版本用于公平对照。每个模块需要定义输入输出、单位、时间尺度、证据、适用范围和不确定性。

参考： [PatientSim](https://github.com/dek924/PatientSim)、[IPIP](https://ipip.ori.org/)、[PerTRAIN](https://doi.org/10.5334/pme.2379)、[AlphaGenome](https://www.nature.com/articles/s41586-025-10014-0)、[PhysiCell](https://github.com/MathCancer/PhysiCell)、[Vivarium](https://github.com/vivarium-collective/vivarium-core)。
